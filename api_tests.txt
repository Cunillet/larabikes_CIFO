*** TEST 1: REGISTER ? ? 200 + token ***
POST /api/register
--------------------------------------------------------------------------------
curl -s -X POST http://localhost:8080/api/register \
  -H "Content-Type: application/json" \
  -d '{"name":"API Tester","email":"api@test.com","password":"Test1234","password_confirmation":"Test1234","birth_date":"1995-06-20"}' | jq .

===============================================================================
  IMPORTANT NOTES
===============================================================================

- jq es opcional (formatea JSON). Sin jq se ve el JSON plano.
- Las rutas protegidas requieren header: Authorization: Bearer <token>
- El token se obtiene de POST /api/register o POST /api/login
- Respuestas API: { success, status, data?, message?, errors? }
- Errores comunes:
    401 ? No autenticado (token faltante o inv?lido)
    403 ? No autorizado (no eres owner/admin)
    404 ? Recurso no encontrado
    422 ? Error de validaci?n
- Campos obligatorios al crear bike: brand, model, price
- Al registrarse: name, email, password, password_confirmation
- user_id se asigna automaticamente al crear si estas autenticado
